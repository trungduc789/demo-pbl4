1. CẤU TRÚC TỔ CHỨC THƯ MỤC DỰ ÁN (CLEAN ARCHITECTURE)
--------------------------------------------------------------------------------
NetworkMonitor/
│
├── main.py                          # Điểm khởi chạy ứng dụng độc lập (Standalone GUI)
├── admin_main.py                    # Điểm khởi chạy Máy Chủ Quản Trị tập trung (Admin Server)
├── client_main.py                   # Điểm khởi chạy Máy Con (Client Agent chạy nền)
├── requirements.txt                 # Danh sách các thư viện Python phụ thuộc cần thiết
├── pharse1.txt                      # Ghi chú yêu cầu và lộ trình hoàn thiện giai đoạn 1
├── tổng quan dự án .txt             # Bản tóm tắt tổng quan kiến trúc dự án
│
├── config/                          # Tầng cấu hình (Configuration Layer)
│   ├── __init__.py
│   └── settings.py                  # Cấu hình chu kỳ lấy mẫu, kích thước bộ đệm, cổng mạng Server-Client
│
├── models/                          # Tầng thực thể (Domain Models)
│   ├── __init__.py
│   ├── network_sample.py            # Cấu trúc dữ liệu: RawNetworkSample, BandwidthSpeed, ProcessNetworkSample
│   └── network_protocol.py          # Cấu trúc gói tin truyền thông TCP JSON-based giữa Admin và Client
│
├── infrastructure/                  # Tầng hạ tầng & Tương tác Kernel/Hệ điều hành (Infrastructure Layer)
│   ├── __init__.py
│   ├── network_collector.py         # Lấy thông số byte truyền/nhận từ card mạng qua psutil
│   ├── etw_consumer.py              # Đọc sự kiện gói tin kernel TCP/IP thông qua Event Tracing for Windows (ETW API)
│   └── packet_shaper.py             # Can thiệp an ninh chặn mạng (Firewall) & bóp băng thông (WinDivert Token Bucket)
│
├── application/                     # Tầng nghiệp vụ (Application Layer)
│   ├── __init__.py
│   ├── bandwidth_calculator.py      # Tính toán delta tốc độ upload/download (KB/s, MB/s)
│   ├── monitor_service.py           # Điều phối luồng dữ liệu trung tâm của ứng dụng giám sát
│   ├── fleet_manager_service.py     # Quản lý mạng lưới máy trạm tập trung cho Admin Server
│   └── client_agent_service.py      # Dịch vụ ngầm kết nối máy trạm tới Admin Server
│
├── presentation/                    # Tầng giao diện người dùng (Presentation Layer - GUI)
│   ├── __init__.py
│   ├── dashboard.py                 # Giao diện đồ họa đa tab PyQt6 + PyQtGraph thời gian thực phong cách GlassWire
│   ├── admin_fleet_view.py          # Giao diện quản lý danh sách máy trạm tập trung
│   └── protect_view.py              # Giao diện điều khiển chính sách chặn & bóp băng thông
│
├── logs/                            # Thư mục lưu nhật ký hệ thống
│   ├── policies.log                 # Lịch sử các thao tác chính sách mạng (Block/QoS)
│   └── connections.log              # Lịch sử socket kết nối mạng
│
└── utils/                           # Tiện ích bổ trợ (Utilities)
    ├── file_logger.py               # Quản lý ghi nhật ký file văn bản thread-safe
    └── safe_print.py                # Hàm in log an toàn, tránh lỗi encode tiếng Việt UTF-8 trên Windows console


2. MỤC TIÊU VÀ ĐẶC TẢ HỆ THỐNG
--------------------------------------------------------------------------------
- Xây dựng ứng dụng giám sát và quản lý băng thông mạng trên hệ điều hành Windows theo mô hình Clean Architecture (Domain - Infrastructure - Application - Presentation).
- Sử dụng trực tiếp các API hệ điều hành và thư viện cấp thấp (Win32 API, Event Tracing for Windows - ETW, psutil, WinDivert) để tương tác trực tiếp với Kernel lấy thông số lưu lượng chính xác theo thời gian thực và can thiệp điều phối băng thông.
- Thiết kế theo kiến trúc Agent hỗ trợ quản trị tập trung nhiều máy tính trong mạng nội bộ (LAN) qua giao thức TCP.
- Lưu trữ lịch sử thao tác an ninh an toàn, nhẹ và độc lập hoàn toàn thông qua hệ thống File Logging (logs/policies.log).


3. CÁC TÍNH NĂNG CHÍNH CỦA HỆ THỐNG
--------------------------------------------------------------------------------
a. Giám sát băng thông thời gian thực (Traffic Monitor):
   - Biểu đồ sóng lưu lượng Upload/Download độ mượt cao, ứng dụng bộ lọc Gaussian và thuật toán nội suy Hermite chống rung giật.
   - Thống kê chi tiết lưu lượng tải xuống, tải lên, phân chia tỷ lệ lưu lượng WAN/LAN.
   - Scrubber thời gian thực: Tua lại, chọn một điểm bất kỳ trên đồ thị để dừng biểu đồ, xem chi tiết tốc độ và mốc thời gian tại điểm đó; ấn tiếp tục để vẽ lại theo thời gian thực.
   - Theo dõi băng thông tiêu thụ theo từng tiến trình (Process) ứng dụng riêng biệt.

b. Bảo vệ & Điều tiết lưu lượng mạng (GlassWire Protect / QoS):
   - Chặn kết nối mạng (Block/Unblock) của ứng dụng chỉ định qua Windows Firewall.
   - Giới hạn tốc độ truyền dữ liệu (Bandwidth Throttling) thời gian thực bằng WinDivert Kernel Packet Shaper (Token Bucket).
   - Kiểm tra tính xác thực của file thực thi ứng dụng.

c. Quét & Giám sát kết nối mạng (Network Scanner):
   - Bảng theo dõi toàn bộ Socket kết nối mạng đang hoạt động trên hệ thống (IP nguồn/đích, Cổng, Giao thức TCP/UDP, Trạng thái kết nối, Tên tiến trình).

d. Nhật ký thao tác & Chính sách an ninh (Log Analysis):
   - Lưu trữ toàn bộ lịch sử can thiệp an ninh (Chặn, Bỏ chặn, Bóp băng thông) trực tiếp vào file log `logs/policies.log` theo chuẩn cấu trúc dễ đọc, Thread-Safe.
   - Lưu trữ các phiên kết nối mạng TCP/UDP mới vào `logs/connections.log`.
   - Giao diện Log Analysis trực quan với bảng tra cứu, hỗ trợ tìm kiếm và lọc sự kiện theo tên tiến trình, hành động.

e. Giám sát tài nguyên phần cứng (Hardware Resources):
   - Theo dõi thời gian thực mức sử dụng CPU, RAM và tốc độ đọc/ghi ổ đĩa (Disk I/O).


4. CÔNG NGHỆ VÀ THƯ VIỆN SỬ DỤNG
--------------------------------------------------------------------------------
- Ngôn ngữ: Python 3.10+
- Giao diện người dùng: PyQt6, PyQtGraph
- Tương tác hệ thống & Kernel: psutil, ctypes, Win32 API (advapi32, ETW)
- Điều phối gói tin Kernel: pydivert (WinDivert 64-bit kernel driver)
- Tính toán dữ liệu: NumPy
- Hệ thống ghi nhật ký: Thread-safe File Logging (logs/policies.log, logs/connections.log)
